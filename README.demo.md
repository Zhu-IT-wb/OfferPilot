# OfferPilot

> 以飞书为交互入口的求职管理与项目面试训练 Agent。

OfferPilot 通过自然语言管理投递与面试，检索面试知识，并在配套网页中分析 GitHub 源码、开展项目面试训练。主 Agent 基于 LangGraph ReAct 循环执行任务：调用工具、观察结果、调整操作，在需要用户确认时暂停并恢复。

**技术栈：** Python · FastAPI · LangGraph · MCP / FastMCP · Qdrant · SQLite · OpenAI-compatible API（DeepSeek / OpenAI）· 飞书开放平台

## 技术实现

### 统一的主 Agent 循环

主 Agent 不按每个业务功能新增图分支。工具成功、失败或需要补充信息时，结果都回到模型，继续决定下一步；可选计划记录目标与进度，不作为固定脚本执行。

- **可恢复交互：** checkpoint 保存运行状态；`interrupt` 暂停确认和信息收集。自然语言回复由模型解释，程序约束用户归属、允许动作和已审批参数。
- **执行约束：** 工具统一声明参数模型与影响级别；支持安全的只读并行，写操作按策略审批。通过调用预算、重复行为检测和完成检查限制无效循环。
- **上下文压缩：** 每次调用前统计系统提示、工具定义和消息预算；将已闭合的历史工具交互压缩为紧凑回执，较老对话整理为结构化摘要，保留当前任务、待确认参数、错误及未配对调用。
- **持久化与隔离：** 图状态、业务数据、原始事件和工具操作回执分别管理；请求去重与操作账本辅助避免重复写入。业务读写和私有检索证据绑定可信用户身份，checkpoint 本身不保证外部操作恰好执行一次。

源码入口：[Agent Runtime](backend/app/agents/runtime.py) · [上下文管理](backend/app/services/agent_context.py) · [执行账本](backend/app/services/agent_runtime_store.py) · [工具注册](backend/app/tools/runtime_tools.py)

### 源码分析与知识检索

- **源码分析：** 使用独立的只读分析 Runtime 主动探索仓库，限制模型、工具和 Token 预算，并输出可核对的源码证据。不会执行仓库的构建、测试或任意 Shell 脚本。
- **混合 RAG：** FastMCP 提供检索与证据读取接口；Qdrant 融合 BGE-small-zh 稠密向量和 BM25 稀疏召回，通过 RRF 排序。主 Agent 获取证据后统一生成回答。
- **入口分工：** 飞书承接主 Agent 对话；Web 承接项目导入、档案确认、学习作答和多轮项目训练。这些 Web 流程有各自的服务逻辑，不全部经过主 Agent 状态图。

源码入口：[项目分析](backend/app/project_analysis/) · [MCP 适配层](backend/app/tools/runtime_mcp_tools.py) · [项目训练](backend/app/services/project_training.py)

## 补充能力与边界

| 能力 | 当前范围 |
| --- | --- |
| LeetCode 练习 | Hot 100 推荐、题目链接、用户自报完成情况与间隔复习；不自动读取 LeetCode 提交结果。 |
| 八股学习 | Web 文字 / 语音作答、回答评估、掌握度及薄弱点记录。 |
| 复习排期 | 结合已有薄弱点、面试时间及可用窗口生成复习 session；不是自动分析岗位 JD。 |
| 日历降级 | 个人日历忙闲读取需要额外授权；不可用时可使用本地信息排期，并说明限制。 |

演示以本地单进程部署为前提。飞书权限、模型可用性、MCP / Qdrant 和知识索引需分别配置；服务健康检查通过不等于所有外部集成都已就绪。

## 本地运行

需要 Python 3.10+；源码分析还需要 Git。以下命令在仓库根目录执行，首次配置时创建独立虚拟环境：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
if (-not (Test-Path -LiteralPath '.env')) {
    Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
```

按 [配置模板](backend/.env.example) 填写模型、飞书及存储配置后启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 健康检查：<http://127.0.0.1:8000/api/health>
- 项目入口：<http://127.0.0.1:8000/study/projects>
- 飞书回调需要可访问的 HTTPS 地址。配套 Web 页使用飞书身份登录；公开地址、OAuth 回调和应用权限须与本地配置一致。
- 知识检索需启用 RAG、准备知识语料及本地嵌入模型；系统通过 stdio 使用 MCP 服务，默认使用 Qdrant Local 索引，无需另起 Qdrant 容器。详见 [后端配置与运行说明](backend/README.md)。不要提交真实 `.env`、数据库或访问令牌。
