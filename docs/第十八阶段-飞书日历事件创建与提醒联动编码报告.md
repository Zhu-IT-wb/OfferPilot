# 第十八阶段：飞书日历事件创建与提醒联动编码报告

## 1. 阶段目标

第十七阶段已经可以在用户确认后记录面试安排：

```text
明天早上八点，深信服约我一面
确认
```

并写入本地 `interview_schedules`。

本阶段目标是把这条面试安排进一步同步到飞书日历：

```text
本地面试安排
-> 解析中文时间
-> 调用飞书日历创建日程
-> 设置提前 30 分钟提醒
-> 保存 calendar_event_id
```

## 2. 本阶段完成内容

### 2.1 增加飞书日历配置

修改文件：

```text
backend/app/core/config.py
```

新增配置：

```text
FEISHU_CALENDAR_SYNC_ENABLED
FEISHU_CALENDAR_ID
FEISHU_CALENDAR_TIMEZONE
FEISHU_INTERVIEW_EVENT_DURATION_MINUTES
```

默认行为：

```text
FEISHU_CALENDAR_SYNC_ENABLED=false
```

也就是说，如果没有显式开启日历同步，OfferPilot 仍然只写本地数据库，不会主动请求飞书日历 API。

### 2.2 增加同步版飞书 OpenAPI 调用能力

修改文件：

```text
backend/app/services/feishu_service.py
```

新增：

- `FeishuCalendarEventResult`
- `FeishuCalendarService`
- `get_tenant_access_token_sync`
- `_post_json_sync`

这样同步工具层可以在不改动现有 Agent async 架构的情况下调用飞书日历。

### 2.3 封装飞书日历创建事件

新增方法：

```python
FeishuCalendarService.create_interview_event(...)
```

创建事件时会构造：

```json
{
  "summary": "OfferPilot 面试：深信服 - AI 应用开发（一面）",
  "description": "原始用户消息",
  "start_time": {
    "timestamp": "...",
    "timezone": "Asia/Shanghai"
  },
  "end_time": {
    "timestamp": "...",
    "timezone": "Asia/Shanghai"
  },
  "reminders": [
    {
      "minutes": 30
    }
  ]
}
```

调用路径：

```text
POST /calendar/v4/calendars/{calendar_id}/events
```

### 2.4 增加中文时间解析

修改文件：

```text
backend/app/services/feishu_service.py
```

新增：

```python
parse_chinese_datetime(...)
```

当前覆盖高频表达：

```text
今天下午三点
今晚八点
明天早上八点
后天下午两点半
下周一上午十点
```

解析失败时不会影响本地写库，只会跳过日历同步并在回复中提示。

### 2.5 Repository 支持保存 calendar_event_id

修改文件：

```text
backend/app/repositories/offerpilot_repository.py
backend/app/repositories/sqlite_offerpilot_repository.py
```

新增：

```python
update_interview_schedule_calendar_event(...)
```

飞书日历创建成功后，将返回的 `calendar_event_id` 回写到本地 `interview_schedules`。

### 2.6 投递更新工具接入日历同步

修改文件：

```text
backend/app/tools/offerpilot_tools.py
```

`update_application` 在创建面试安排后会尝试同步飞书日历。

同步结果会放入工具返回值：

```json
{
  "calendar_sync": {
    "synced": true,
    "status": "synced",
    "calendar_event_id": "..."
  }
}
```

如果没有开启同步：

```json
{
  "calendar_sync": {
    "synced": false,
    "status": "disabled"
  }
}
```

如果飞书 API 调用失败：

```json
{
  "calendar_sync": {
    "synced": false,
    "status": "failed",
    "error": "..."
  }
}
```

## 3. 当前用户体验

同步成功时：

```text
已更新投递进度：
公司：深信服
岗位：AI 应用开发
状态：一面阶段
轮次：一面
时间：明天早上八点
已记录面试安排，默认提前 30 分钟提醒。
已同步到飞书日历。
```

未开启同步时：

```text
已记录面试安排，默认提前 30 分钟提醒。
飞书日历同步未开启，当前只保存到 OfferPilot。
```

## 5. 当前限制

- `.env.example` 本阶段未能自动写入，需要手动补充日历配置；
- 时间解析仍是轻量规则，不支持所有自然语言表达；
- 当前只创建日历事件，还没有单独添加参会人；
- 真实飞书联调前，需要在飞书开放平台开启日历相关权限并重新发布应用。
