# 第二十六阶段：飞书多维表格拉取同步修复报告

## 问题背景

用户在飞书多维表格中手动编辑投递记录后，本地 SQLite 数据库没有变化。

排查发现：

1. 飞书聊天消息可以正常进入 `/api/feishu/events`。
2. cloudflared 公网地址可以访问后端。
3. 后端服务正常运行。
4. 但用户手动编辑多维表格记录时，`backend/data/feishu_events.log` 没有新增真实的 `drive.file.bitable_record_changed_v1` 事件。

因此根因不是数据库写入失败，而是飞书没有把这次表格编辑作为事件回调推送给 OfferPilot。

## 修复方案

保留事件回调同步能力，同时新增更稳定的“主动拉取同步”：

```text
OfferPilot 后端定时读取飞书多维表格
-> 遍历投递记录
-> 根据 OfferPilot记录ID 或 record_id 映射
-> 回写 SQLite 数据库
```

这样即使飞书事件没有触发，数据库也会在轮询周期内同步。

## 实现内容

### 1. 新增配置

`backend/app/core/config.py`

新增：

```text
FEISHU_BITABLE_PULL_SYNC_ENABLED
FEISHU_BITABLE_PULL_SYNC_INTERVAL_SECONDS
FEISHU_BITABLE_PULL_SYNC_PAGE_SIZE
```

默认行为：

- 如果 `FEISHU_BITABLE_SYNC_ENABLED=true`，则默认开启拉取同步。
- 默认每 30 秒同步一次。
- 默认每页拉取 100 条记录。

### 2. 新增飞书记录列表 API

`backend/app/services/feishu_service.py`

新增：

- `FeishuBitableRecordListResult`
- `FeishuBitableService.list_records`

用于调用：

```text
GET /bitable/v1/apps/{app_token}/tables/{table_id}/records
```

### 3. 拆分字段级写库能力

`backend/app/services/bitable_sync_service.py`

新增：

```python
sync_bitable_record_fields_to_repository(...)
```

这样从事件回调或主动拉取拿到字段后，都能复用同一套写库逻辑。

### 4. 新增后台拉取同步服务

新增文件：

```text
backend/app/services/bitable_pull_sync_service.py
```

核心能力：

- 定时拉取飞书多维表格全部记录。
- 将每条记录同步到本地 SQLite。
- 支持分页。
- 支持手动 `sync_once()` 立即同步。

### 5. 接入 FastAPI 生命周期

`backend/app/main.py`

服务启动时自动启动拉取同步任务；服务关闭时停止任务。

## 当前结论

飞书事件回调仍然保留，但真实可靠的同步路径改为：

```text
飞书多维表格作为可编辑工作台
OfferPilot 后端定时拉取
SQLite 作为本地业务数据库
```

这比完全依赖飞书记录变更事件更适合当前 MVP。

## 删除同步补充（2026-09-08）

- 手动删除行后，事件回调读取当前记录；明确收到 `RecordIdNotFound` 时，按已登记的表格、用户和记录映射标记本地投递已删除。
- 定时拉取先保存本轮开始时的映射，再完整读取所有分页，逐条复查缺失的旧记录。网络失败、无权限、表不存在、分页不完整都不会当作行删除。
- 删除采用软删除，历史记录、编号和操作回执保留；投递查询和关联面试查询不再展示它。后续新增生成独立的新记录，不覆盖旧记录，也不复用已删除记录的编号。
- 可写映射失效后保留反向映射和删除标记，阻止迟到回调、旧对象及缓存把记录重新创建。入站和出站记录写入共用单进程表级锁。
- 删除表格行不等于取消飞书日历事件：不会自动删除已有日历事件，进行中的日历请求仍保存回执。
- 不处理删除整张数据表、删除整个多维表格或自动恢复被删除的行。清空单元格也不等于删除行。

拉取周期由 `FEISHU_BITABLE_PULL_SYNC_INTERVAL_SECONDS` 控制；必须同时启用 `FEISHU_BITABLE_SYNC_ENABLED` 和 `FEISHU_BITABLE_PULL_SYNC_ENABLED`。事件未送达时由下一轮成功拉取补齐，服务离线期间不会同步。
